# Datos solo para pruebas

`colonias_prueba.csv` tiene 24 colonias **inventadas** (todas se llaman «Ficticia ... (PRUEBA)», con código postal
00000). **No son datos reales y no se cargan en la plataforma**: las pruebas de la semilla (`test_semilla.py`) lo usan
en lugar del catálogo real `db/datos/colonias_juarez.csv`, para que no dependan de él.
Las coordenadas están repartidas por la zona urbana de Ciudad Juárez solo para que los reportes ficticios caigan
dentro del municipio.
