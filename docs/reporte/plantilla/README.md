# Plantilla de Word del reporte

Estilos, numeración, pie de página, tema y logos que usa `generar_docx.py`.

**De dónde salió.** Se extrajo de `docs/REPORTE.docx` del proyecto previo del mismo equipo
([extra-liebres](https://github.com/luisreyna060318-alt/extra-liebres)), un reporte propio generado con `python-docx`. **No es un
documento del docente.** No conserva texto ni datos de aquel proyecto.

`word/media/logos.png` contiene los logotipos del Tecnológico Nacional de México y del Instituto Tecnológico de Ciudad Juárez, que se
usan solo en la portada de este trabajo escolar y pertenecen a esas instituciones.
